# Çoklu dil (i18n)

Yapı Next-Elite'ten esinlenmiştir: diller tek bir JSON'dan yönetilir, dil seçimi
`NEXT_LOCALE` cookie'sinde tutulur, URL'de dil öneki yoktur.

| Ne | Nerede |
| --- | --- |
| Dil listesi, varsayılan dil, yön (ltr/rtl) | `packages/i18n/src/locales.config.json` |
| Çeviri sözlükleri | `apps/web/i18n/messages/<dil>/<namespace>.json` |
| Dil çözümleme + İngilizce yedek | `apps/web/i18n/request.ts` |
| Dil değiştirme (server action) | `packages/i18n/src/locale-actions.ts` |
| Dil seçici bileşeni | `packages/ui/src/makerkit/language-selector.tsx` |
| Sözlük denetimi | `pnpm --filter web i18n:check` |

## Şu an

- Etkin: `tr` (varsayılan), `en`.
- Kayıtlı ama etkin değil: `ru`, `ar`, `es`, `uk`.
- Eksik anahtarlar İngilizceye düşer (ham anahtar görünmez).

## Yeni dil eklemek

1. `locales.config.json` içinde dili `enabled` listesine ekleyin (üst bilgisi `locales` altında zaten kayıtlıdır; yoksa `name`, `nativeName`, `bcp47`, `direction` ile ekleyin).
2. `apps/web/i18n/messages/<dil>/` altına `en` klasöründeki dosyaları çevirerek ekleyin. Tüm namespace'leri çevirmek zorunda değilsiniz.
3. `pnpm --filter web i18n:check` çalıştırın. Yer tutucu (`{name}`, `<b>`) uyuşmazlığı ve fazla anahtar hata verir; eksik anahtarlar raporlanır (`--strict` ile hata sayılır).
4. Yazı tipini kontrol edin (`apps/web/lib/fonts.ts`):
   - `ru`/`uk` için `cyrillic` (ve `cyrillic-ext`) alt kümesini ekleyin.
   - `ar` için Inter Arapça içermez; Arapça bir font (ör. Noto Sans Arabic) ekleyin.

## Arapça (RTL) için hazırlık

- `<html dir>` otomatik olarak dilin yönüne göre ayarlanır.
- Yeni arayüz kodunda yönlü yerine mantıksal Tailwind sınıfları kullanın:
  `ms-*`/`me-*`, `ps-*`/`pe-*`, `text-start`/`text-end`, `start-*`/`end-*`
  (`ml-*`, `pr-*`, `text-left`, `left-*` yerine). Böylece Arapça eklendiğinde
  düzen kendiliğinden aynalanır.
- Yönlü ikonlar (ok, geri) için `rtl:rotate-180` kullanın.

## Rusça ve Ukraynaca notları

- Çoğul biçimleri için ICU çoğul sözdizimi kullanın:
  `{count, plural, one {# dosya} few {# dosya} many {# dosya} other {# dosya}}`.
- Para, tarih ve sayılar `Intl` ile dile göre biçimlendirilmelidir
  (`getLocaleBcp47(locale)` yardımcıdır).

## Tasarım kararı: cookie, URL öneki değil

Dil cookie'den okunduğu için kök layout isteğe bağlı veri okur. Bu nedenle
**Cache Components / Partial Prerendering kapalıdır** (`next.config.mjs`).
Giriş gerektiren panel için kayıp küçüktür. İleride herkese açık, SEO'ya duyarlı
sayfalar için dil bazlı URL (`/tr`, `/en`) gerekirse, rotalar bir `[locale]`
segmentine taşınır ve Cache Components yeniden açılabilir.
